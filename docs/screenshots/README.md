# NOVA Portfolio Screenshots Guide

This directory holds the interface screenshots for portfolio presentation and GitHub documentation.

## Required Screenshots

Capture high-resolution screenshots (16:9 or 16:10 aspect ratio, dark theme recommended) and save them with these exact filenames:

| Filename | View | Description |
|----------|------|-------------|
| `landing.png` | Landing Page (`/`) | Full hero section, navigation bar, and feature overview |
| `dashboard.png` | Dashboard (`/dashboard`) | Active projects grid, workspace search, and header with notification bell |
| `project-board.png` | Project Kanban Board (`/projects/:id`) | Multi-column Kanban board (TODO, In Progress, In Review, Done) with task cards |
| `task-detail.png` | Task Modal Inspector | Open task modal showing title, assignee selector, status dropdown, and comment feed |
| `members.png` | Workspace Members Dialog | Workspace member roster modal showing roles (Owner, Admin, Member) and invite input |
| `notifications.png` | Notifications Drawer | Open notification popover showing assignment alerts and read/unread states |

These images are referenced directly in the project [README.md](../../README.md).
